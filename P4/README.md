# P4 - README and Git Tags

## Objective
To understand README files, Markdown formatting and Git tags.

## About This Practical
This practical demonstrates how to document a project using Markdown and manage versions using Git tags.

## Topics Covered
- Creating README files
- Markdown headings
- Bold and italic text
- Ordered and unordered lists
- Adding links
- Git tags

## Git Commands

### View all tags
```bash
git tag
```

### Create a tag
```bash
git tag -a v1.0 -m "P4 completed"
```

### Push a tag
```bash
git push origin v1.0
```

### View tag details
```bash
git show v1.0
```

## Conclusion
Learned how to create and format README files and manage project versions using Git tags.
