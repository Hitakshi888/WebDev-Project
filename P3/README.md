# P3 - Git Workflow and Feature Branches

## Objective
To understand Git branching, committing, pushing and merging.

## Git Commands Practiced

1. git branch - View branches
2. git switch -c feature/p3  - Create a feature branch
3. git add . - Stage changes
4. git commit -m "message" - Commit changes
5. git push -u origin feature/p3- Push branch to GitHub
6. git switch main - Switch to main branch
7. git merge feature/p3 - Merge feature branch

## Conclusion
Learned how to create and manage feature branches using Git.
